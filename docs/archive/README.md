# Archive

The working record — phase audits, design explorations, competitive analyses,
autopsies and the documents that argued each decision before it was made.

It is here because it is evidence, not because it is a reading path. Nothing
in this directory is required to understand, run, or evaluate ATTEST; the
fifteen documents one level up are. If a claim in the current documentation
looks unsupported, the argument behind it is almost certainly in here.

Kept whole and unedited. Some of it records conclusions that were later
reversed — `PRODUCT-DESIGN-29.md` proposed a visual system that Phase 31
replaced, and `COMPETITIVE-BENCHMARK.md` quotes a figure that
`benchmark/anchoring.json` later superseded. That is what a working record
looks like.
